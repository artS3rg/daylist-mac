# Дела

Локальный список задач с названиями и описаниями для Mac с Apple Silicon и macOS 13 или новее. По будням приложение напоминает об открытых задачах в 11:00 и предлагает составить список на завтра в 20:00 по времени Mac.

[Скачать готовое приложение](https://github.com/artS3rg/daylist-mac/releases/latest/download/Daylist-Apple-Silicon.zip)

Распакуйте ZIP, перенесите «Дела» в «Программы» и откройте. Разрешите уведомления при первом запуске. Если macOS попросит подтвердить запуск приложения с локальной подписью, следуйте [инструкции Apple](https://support.apple.com/ru-ru/102445).

Кнопка с палитрой переключает светлую, тёмную или системную тему и задаёт цвет кнопок и отметок. Настройки оформления сохраняются на Mac.

После установки или обновления один раз откройте «Дела» и разрешите уведомления. Если приложение предложит включить фоновую работу, перейдите по кнопке в системные настройки. Две календарные службы macOS обрабатывают 11:00 и 20:00 отдельно, даже после выхода через ⌘Q. Когда запланированное время приходится на сон, службы выполняются при пробуждении. Утреннее напоминание учитывает сохранённые открытые задачи. В выходные баннеры пропускаются.
